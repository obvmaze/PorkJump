# Pork Jump 🐷

Hochkant endless Jump 'n' Run mit John Pork in der Hauptrolle

## Spielen: https://claude.ai/artifact/2oTBmyx1Kstr6P5sn3DS4i

- **Lokal:** `index.html` im Browser öffnen (Doppelklick reicht).
- **Am PC:** Pfeiltasten / A-D zum Steuern, `P` oder `Esc` = Pause, `Enter` = Start.
- **Am Handy:** Buttons unten links/rechts gedrückt halten.

## Features

Aktuelle Version: **1.1**. Alle Änderungen stehen in [PATCHNOTES.md](PATCHNOTES.md).

- Unendliche, zufällige Plattformen – wird mit der Höhe schwerer, mit leichten und harten Passagen; ab und zu bewegliche Plattformen
- 11 Comic-Welten, alle 400 m ein Wechsel: Sonnenaufgang-Strand, Verwunschener Wald, Schneeberge, Drachentempel, Canyon im Abendrot, Dunkle Grotte, Zuckerland, Giftlabor, Wolkenkönigreich, Polarlicht-Nacht, Weltall. Die Reihenfolge ist jeden Run zufällig.
- Gegenstände: **Trampolin** (Mega-Sprung), **Federschuhe** (15 s doppelt so hohe Sprünge, ab und zu ein Salto), **Biene** (trägt dich 3 s nach oben)
- Meter-Anzeige, Pause-Menü (Sound an/aus, Hauptmenü), Bestleistung lokal gespeichert, Rekord-Linie im Level

## Dateien

- `index.html` – Aufbau (Menüs, Buttons)
- `style.css` – Aussehen der Menüs/Buttons
- `game.js` – das ganze Spiel (Physik, Zeichnen, Welten, Sound). Gameplay-Werte stehen ganz oben.
